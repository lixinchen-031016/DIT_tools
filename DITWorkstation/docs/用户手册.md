# DIT 工作站 — 专业摄影数据管理 用户手册

## 应用总览

**应用名称**：DIT 工作站 — 专业摄影数据管理

DIT 工作站是一款面向专业摄影工作流的桌面应用，覆盖从媒体导入、数据备份、RAW 提取、文件重命名、拍摄日志、素材信息、素材检索到报告生成的完整数据管理链路，帮助 DIT（数字影像工程师）在片场高效、安全地管理海量摄影素材。

### 主窗口布局

- **顶部菜单栏**：含「设置」菜单（快捷键 `Ctrl+,`，macOS 为 `Cmd+,`），可打开设置对话框。
- **左侧导航栏**：宽度 200px，深色主题，列示 9 个功能模块入口。
- **右侧内容区**：展示当前选中模块的操作界面。
- **底部状态栏**：显示当前任务状态与存储卡检测提示。
- **窗口尺寸**：最小 1200×800，默认 1400×900。

### 导航栏功能模块

| 序号 | 图标 | 模块名称 | 说明 |
|------|------|----------|------|
| 1 | 🏠 | 项目概览 | 当前项目进度看板与 SOP 操作链引导 |
| 2 | 📁 | 媒体导入 | 扫描并导入源文件夹中的图片/视频/RAW 文件 |
| 3 | 📦 | 数据备份 | 多目标并行备份源数据，支持校验与 MHL 清单 |
| 4 | 🎞 | RAW 提取 | 依据筛选后 JPG 反查并提取对应 RAW 文件 |
| 5 | ✏️ | 文件重命名 | 按命名规则模板批量重命名文件 |
| 6 | 📋 | 拍摄日志 | 记录场景/镜头/镜次信息并关联素材 |
| 7 | 🔍 | 素材检索 | 按项目/关键词/场景/镜头/日志/评级等多条件检索素材 |
| 8 | ℹ️ | 素材信息 | 查看素材 EXIF 与元数据详情，设置镜次评级 |
| 9 | 📊 | 报告生成 | 生成数据备份报告或素材统计报告（PDF） |

### 数据与文件位置

| 项目 | 开发模式路径 | 打包后路径（macOS） | 打包后路径（Windows） |
|------|-------------|---------------------|----------------------|
| 数据库文件 | `data/dit_workstation.db` | `~/Library/Application Support/DITWorkstation/` | `%APPDATA%\DITWorkstation\` |
| 报告输出目录 | `~/Documents/DIT_Reports/` | 同左 | 同左 |
| 日志文件目录 | `~/.dit_workstation/logs/` | 同左 | 同左 |

> 若默认数据目录不可写（如 macOS TCC 权限拒绝），自动回退到 `~/.ditworkstation/`。

### 标准 SOP 操作链

DIT 工作站围绕以下标准操作链设计：

```
⓪ 创建工作区 → ① 在工作区内创建项目 → ② 媒体导入 → ③ 数据备份 → ④ 拍摄日志补录 → ⑤ 素材检索/信息/报告
```

- **工作区**对应一个物理目录（如「2026 春季广告片」对应 `/Volumes/Work/2026SpringAd`）
- **项目**是单次拍摄任务的素材集合（如「镜头组A」），归属于某个工作区
- 一个工作区下可创建多个项目

## 首次启动：首启向导

首次启动应用且数据库中无任何项目时，会自动弹出首启向导，引导完成项目初始化。

### 向导流程（共 5 步）

1. **欢迎页**：介绍 SOP 操作链与工作区/项目概念
2. **创建工作区**：输入工作区名称（必填）、物理目录（可选，浏览选择）、描述（可选）
3. **创建项目**：在工作区内创建第一个项目，输入项目名称（必填）与描述（可选）
4. **SOP 操作链提示**：媒体导入、数据备份、拍摄日志补录的详细操作说明
5. **完成页**：后续工作流建议，点击「完成」自动跳转到「媒体导入」视图

### 注意事项

- 向导为非阻塞对话框，可随时取消；取消后仍可正常使用主程序
- 完成向导后，创建的工作区和项目会自动设为当前全局工作区/项目
- 后续如需新建工作区或项目，可在各功能模块的左侧面板操作

## 工作区与项目管理

### 工作区-项目两级结构

DIT 工作站采用「工作区 → 项目」两级结构组织素材：

- **工作区**：项目的父级容器，对应一个物理目录，用于组织一组相关项目
- **项目**：单次拍摄任务的素材集合，归属于某个工作区
- 严格 1:N 关系：一个工作区下可创建多个项目

### 工作区操作

各功能模块左侧面板顶部均有工作区下拉框与操作按钮：

- **选择工作区**：从下拉框切换工作区，项目列表自动过滤为该工作区下的项目
- **新建工作区**：点击「+ 新建工作区」按钮，弹出对话框填写名称、物理目录、描述
- **编辑工作区**：点击「编辑」按钮修改当前工作区信息
- **删除工作区**：
  - 默认工作区（id='default'）不可删除
  - 删除非默认工作区时，其下所有项目自动归入默认工作区
  - 删除工作区不会删除项目内的实际文件

### 项目操作

选择工作区后，项目列表显示该工作区下的所有项目：

- **新建项目**：点击「+ 新建项目」按钮，输入项目名称与描述（必须先选择工作区）
- **删除项目**：选中项目后点击「删除」按钮（事务级联清理素材与日志记录，不删除实际文件）
- **切换项目**：点击项目列表中的项目，全局当前项目会同步切换，其他视图自动刷新

## 模块 1: 项目概览

### 界面布局

- **顶部**：工作区/项目选择器
- **中部**：4 张统计卡片，展示当前项目的进度数据
- **项目管理区**：🗜 归档当前项目… / ↩ 恢复项目… / 🧩 从模板新建项目… / 💾 保存当前项目为模板…
- **底部**：SOP 操作链引导区，提供「下一步」提示与 4 个快捷跳转按钮；下方展示「🕘 最近操作」审计记录（最近 5 条）

### 统计卡片

| 卡片 | 显示内容 |
|------|----------|
| 素材总数 | 已导入的素材数量与总大小 |
| 备份覆盖 | 已备份素材占比 |
| 日志关联 | 已关联拍摄日志的素材数量 |
| 评级覆盖 | 已设置评级的素材数量 |

### SOP 快捷跳转

4 个按钮根据当前进度提供跳转：

- **① 媒体导入**：跳转到媒体导入视图
- **② 数据备份**：跳转到数据备份视图
- **③ 拍摄日志**：跳转到拍摄日志视图
- **④ 生成报告**：跳转到报告生成视图

### 动态提示

底部提示文案会根据项目进度动态生成，例如：
- 无素材时：「建议从媒体导入开始」
- 有素材未备份时：「建议尽快进行数据备份」
- 有素材未关联日志时：「建议补录拍摄日志」

### 项目管理

#### 归档当前项目

- 点击「🗜 归档当前项目…」把项目信息 + 拍摄日志 + 素材元数据打包为 zip（可选附带素材文件副本）。
- 归档包内含 `manifest.json` / `assets.json` / `logs.json` / `checksums.txt`，自包含、可交接。
- 不附带素材文件时体积小，适合日常备份元数据；附带素材文件时适合长期保存与项目交接。

#### 恢复项目

- 点击「↩ 恢复项目…」选择归档 zip，从归档包重建项目到当前工作区。
- 可选还原素材文件：还原到临时目录并自动校验校验和，全部通过后才移入目标位置，失败不会留下半成品。
- 与现有项目重名时自动追加时间戳后缀，不会覆盖。
- 恢复过程内置安全防护：校验 zip 成员路径（拒绝绝对路径 / 父目录跳转）、限制解压大小并阻止符号链接越界。

#### 项目模板

- 「🧩 从模板新建项目…」：选择模板 → 填写名称与工作区 → 一键建项（模板中的描述 / 工作目录自动预填）。
- 「💾 保存当前项目为模板…」：把当前项目的名称 / 描述 / 工作目录保存为模板，供后续复用。
- 首次初始化自动预置「标准影视项目」模板；模板通过「项目概览」的模板按钮创建与复用。

#### 最近操作

- 页面底部展示最近 5 条操作审计记录（导入、备份、RAW 提取、重命名、评级、标签更新等自动留痕）。

## 模块 2: 媒体导入

### 界面布局

界面采用左右分栏结构：

- **左侧**：工作区下拉框 + 项目列表 + 「+ 新建工作区」/「+ 新建项目」按钮。
- **右侧**：
  - **导入源**：文件夹选择输入框 + 「浏览...」按钮。
  - **扫描选项**：复选框组（递归扫描 / 包含图片 / 包含视频 / 包含 RAW）+ 「扫描」按钮。
  - **待导入文件表格**：6 列（导入 / 文件名 / 类型 / 大小 / 修改时间 / 路径），支持「☑ 全选 / 全不选 / ⇄ 反选」；选中行在右侧显示缩略图预览。
  - **按时间筛选**：勾选后只导入指定时间范围内的文件（按文件修改时间，存储卡上通常等于拍摄时间），提供「今天 / 最近7天 / 清除范围」快捷按钮。
  - **导入选项**：计算校验和复选框、复制到工作区复选框（自动填充工作区目录）、关联拍摄日志下拉框。
  - **操作按钮**：导入按钮 + 取消按钮。
  - **进度与状态**：进度条、状态标签、导入日志。

### 操作流程

1. 在左侧选择工作区，再选择项目（或点「+ 新建项目」创建新项目）。
2. 点击「浏览...」选择包含媒体文件的文件夹。
3. 勾选要扫描的文件类型（图片 / 视频 / RAW），可勾选「递归扫描」包含子文件夹；如需只导入某一天的素材，勾选「按时间筛选」并设置时间范围。
4. 点击「扫描」按钮，待导入文件表格显示扫描结果。
5. 在导入选项中：
   - 勾选「计算校验和」为每个文件生成唯一哈希值用于查重；
   - 如需将文件复制到工作区，勾选「复制到工作区」（目录自动填充为当前工作区路径，无需重新选择）；
   - 如需关联拍摄日志，从下拉框选择已创建的日志（会自动带出 scene / shot 信息）。
6. 点击「导入」按钮开始导入，进度条显示进度，可随时点「取消」中断。
7. 导入完成弹出结果：成功 N 个、跳过 N 个（重复）、失败 N 个。

### 两种导入模式

- **引用模式（默认）**：原文件位置保持不动，仅记录路径到数据库。
- **复制模式（勾选「复制到工作区」）**：将文件复制到当前工作区对应的物理目录，重名文件自动加 `_N` 后缀。

### 查重逻辑

按项目内文件路径查重，已导入的文件会被跳过。

### 注意事项

- 导入前请确保存储卡 / 源文件夹可正常读取。
- 校验和计算会增加导入时间，但便于后续完整性验证。
- 关联拍摄日志后，素材的 scene / shot 字段会自动填充日志对应值。
- 复制模式下目录自动取自当前工作区路径，无需手动选择。
- 缩略图预览基于本地缓存，首次生成稍慢，之后即时显示。

## 模块 3: 数据备份

### 界面布局

- **顶部**：工作区/项目选择器（可选「不关联项目，仅做文件备份」）
- **源路径选择**：输入框 + 「浏览...」按钮。
- **备份方案模板**：方案下拉框 + 「保存当前方案」/「删除方案」按钮（可复用目标列表、校验算法与验证选项）。
- **备份目标列表**：目标路径列表 + 「+ 添加目标」/「移除」按钮；每个目标实时显示磁盘剩余空间（备份前自动预检）。
- **配置区**：校验算法下拉框（XXHash64 / MD5）+ 「拷贝后验证」复选框。
- **操作按钮**：开始备份 / 取消 / 📄 导出 MHL 校验清单 / 🔍 校验已有备份。
- **进度与状态**：进度条（0-1000 精度）、状态标签、操作日志。
- **备份历史**：最近 20 条备份作业记录（时间 / 项目 / 源路径 / 目标数 / 状态 / 失败文件），支持断点续传与失败文件重试。

### 操作流程

1. （可选）在顶部选择要关联的项目；若仅做文件备份可不关联项目。
2. 点击源路径旁的「浏览...」选择存储卡或源文件夹，系统自动扫描显示文件数和总大小。
3. 点击「+ 添加目标」逐个添加备份目标路径（支持多目标并行备份，最多 4 个并行）。
4. 选择校验算法（推荐 XXHash64，速度更快）和是否「拷贝后验证」。
5. （可选）点击「保存当前方案」把本次配置保存为备份方案，下次从下拉框直接选择复用。
6. 点击「开始备份」，系统先对每个目标做磁盘空间预检（空间不足会拒绝启动），再并行拷贝到所有目标。
7. 每个文件拷贝完成后自动验证（如开启），进度条实时更新。
8. 完成后弹出窗口显示每个目标的成功 / 失败状态。
9. 若关联了项目，备份完成后会自动回写素材的 `backup_locations` 字段。

### 断点续传与失败重试

- 备份中断（拔卡 / 断电 / 取消）后，未完成文件会记入备份历史。
- 重新备份时，目标中已存在且校验一致的文件自动跳过，只补拷缺失 / 失败文件。
- 在「备份历史」选中某条作业，可查看失败文件列表；点击「↻ 重试失败文件」只重试失败项，其余文件自动跳过。
- 备份任务运行中会实时保存快照，应用异常退出后重启可恢复到上次进度。

### 校验已有备份

- 点击「🔍 校验已有备份」：按素材记录的备份位置对备份盘做独立完整性校验（存在性 + 校验和比对），可检测位错误 / 文件丢失。
- 仅当备份时关联了项目，素材的备份位置才会被记录，因此该项目素材才能被校验。

### 导出 MHL 校验清单

- 完成一次备份后，点击「📄 导出 MHL 校验清单」可把本次备份的源文件哈希列表导出为 ASC MHL（Media Hash List）2.0 格式 XML 文件，用于交接与第三方核验。

### 技术细节

- 多目标使用线程池并行拷贝（最多 4 个并行）。
- 拷贝缓冲区 8MB，校验和缓冲区 4MB。
- 拷贝后验证：对目标文件重新计算校验和并与源文件比对，不一致则报错。
- 备份前磁盘空间预检：任一目标剩余空间不足则整体取消并提示。

### 注意事项

- 备份过程中不要拔出存储卡。
- 建议始终开启「拷贝后验证」确保数据完整性。
- 多目标备份时，某个目标失败不影响其他目标。
- 关联项目后，备份位置会记录到素材信息中，便于后续追溯。

## 模块 4: RAW 提取

### 界面布局

- **顶部**：工作区/项目选择器（可选「不关联项目，仅提取文件」）
- **路径配置组**：JPG 文件夹、RAW 源文件夹、输出文件夹，各带「浏览...」按钮。
- **选项**：「提取后验证」复选框。
- **操作按钮**：扫描匹配 / 开始提取 / 取消按钮。
- **匹配结果表格**：3 列（JPG 文件 / 匹配 RAW / 状态）。
- **进度与状态**：进度条、状态标签。

### 操作流程

1. （可选）在顶部选择要关联的项目；若仅提取文件可不关联项目。
2. 设置「JPG 文件夹」（筛选后的 JPG 所在目录）。
3. 设置「RAW 源文件夹」（原始 RAW 文件所在目录）。
4. 设置「输出文件夹」（提取后的 RAW 存放目录）。
5. 可勾选「提取后验证」。
6. 点击「扫描匹配」查看 JPG 与 RAW 的匹配结果（状态显示「已匹配」或「未找到」）。
7. 确认匹配结果后点击「开始提取」，系统将匹配的 RAW 文件复制到输出目录。
8. 完成后显示提取数量、未找到数量、失败数量。
9. 若关联了项目，提取出的 RAW 文件会自动入库到该项目，并继承原 JPG 的日志关联（log_id）。

### 匹配逻辑

按文件名 stem（不含扩展名）小写比对，例如 `IMG_001.jpg` 匹配 `IMG_001.cr2`。

### 注意事项

- 确保 JPG 和 RAW 文件名前缀一致。
- 重名文件自动加 `_N` 后缀。
- 关联项目后，提取的 RAW 会自动入库并继承 JPG 的日志关联。

## 模块 5: 文件重命名

### 界面布局

- **文件夹选择**：输入框 + 「浏览...」按钮。
- **命名规则组**：可编辑下拉模板（4 种预设 + 自定义）。
- **参数输入框**：场景号 / 镜头号 / 镜次号、前缀 / 起始序号 / 序号位数。
- **操作按钮**：预览 / 执行重命名按钮。
- **预览结果表格**：2 列（原文件名 / 新文件名）。

### 操作流程

1. 点击「浏览...」选择要重命名的文件夹，系统自动扫描文件。
2. 在命名规则下拉框选择或自定义模板。
3. 填写场景号、镜头号、镜次（如 `S001` / `001A` / `T01`）。
4. 设置前缀、起始序号、序号位数（如 `001`）。
5. 点击「预览」查看重命名结果。
6. 确认无误后点击「执行重命名」（不可撤销）。
7. 重命名完成后，数据库中素材的文件路径会自动同步更新。

### 模板变量

| 变量 | 含义 |
|------|------|
| `{scene}` | 场景号 |
| `{shot}` | 镜头号 |
| `{take}` | 镜次号 |
| `{original}` | 原文件名（不含扩展名） |
| `{number}` | 序号（从起始序号开始，按序号位数补零） |
| `{prefix}` | 自定义前缀 |
| `{suffix}` | 自定义后缀 |
| `{date}` | 当前日期（YYYYMMDD） |

### 预设模板

1. `{scene}_{shot}_{take}_{number}`
2. `{scene}_{shot}_{take}_{original}`
3. `{prefix}_{scene}_{number}`
4. `{date}_{scene}_{shot}_{number}`

### 注意事项

- 执行重命名不可撤销，请先预览确认。
- 重名文件自动加 `_N` 后缀防止覆盖。
- 文件扩展名保持不变。
- 重命名后数据库中的素材路径会自动同步，无需重新导入。

## FAQ 常见问题

**Q1: 数据库文件存在哪里？**
A: 开发模式下位于项目目录 `data/dit_workstation.db`；打包后 macOS 位于 `~/Library/Application Support/DITWorkstation/`，Windows 位于 `%APPDATA%\DITWorkstation\`。若默认目录不可写，自动回退到 `~/.ditworkstation/`。

**Q2: 导入时重复文件会怎样？**
A: 系统按项目内文件路径查重，已导入的文件会被自动跳过并计入「跳过」数量。

**Q3: 导入 / 备份过程中可以取消吗？**
A: 可以，点击「取消」按钮即可中断，已处理的部分不受影响。

**Q4: 复制模式下重名文件怎么处理？**
A: 自动在文件名后加 `_N` 后缀（如 `file_1.cr2`、`file_2.cr2`）。

**Q5: 报告中中文显示乱码怎么办？**
A: 系统会自动查找系统中文字体（macOS: PingFang，Windows: 微软雅黑，Linux: 文泉驿 / Noto），请确保系统已安装中文字体。

**Q6: 删除项目会删除实际文件吗？**
A: 不会。删除项目仅删除数据库记录（项目、日志、素材记录），不会删除磁盘上的实际文件。

**Q7: 校验和有什么用？**
A: 校验和是文件的唯一指纹，用于查重和完整性验证。备份后验证可确保拷贝无误。

**Q8: 拍摄日志和素材如何关联？**
A: 有两种方式：1) 创建日志时选择关联素材；2) 在「项目素材」标签页多选素材后创建日志。关联后素材的 scene / shot 会同步日志信息。

**Q9: 工作区和项目是什么关系？**
A: 工作区是项目的父级容器，对应一个物理目录，用于组织一组相关项目。一个工作区下可创建多个项目。默认工作区不可删除，删除非默认工作区时其下项目自动归入默认工作区。

**Q10: 镜次评级怎么使用？**
A: 在「素材信息」视图选中素材后，点击评级按钮（未评级 / ★ 可用 / ★★ 备选 / ★★★ 优选）即可设置。在「素材检索」视图可按评级筛选。「报告生成」的素材统计报告含评级分布统计。

**Q11: 首启向导弹出条件是什么？**
A: 仅在数据库中无任何项目时自动弹出。若取消向导，后续可在各功能模块左侧面板手动创建工作区和项目。

**Q12: 复制到工作区时目录如何确定？**
A: 在「媒体导入」视图勾选「复制到工作区」后，目录自动取自当前选中工作区的物理路径，无需手动选择。若工作区未设置物理目录，则需手动选择。

**Q13: 重命名后数据库记录会更新吗？**
A: 会。执行重命名后，数据库中素材的 `file_path` 会自动同步为新路径，无需重新导入。

**Q14: RAW 提取后能自动入库吗？**
A: 能。在 RAW 提取视图顶部选择要关联的项目后，提取出的 RAW 文件会自动入库到该项目，并继承原 JPG 的日志关联（log_id）。

**Q15: 视频元数据读取失败怎么办？**
A: 视频元数据读取依赖 MediaInfo 库。macOS 请运行 `brew install mediainfo`；Windows 请从 https://mediaarea.net/en/MediaInfo 下载安装。

**Q16: 搜索结果超过 500 条怎么看全部？**
A: 检索结果按页展示（默认每页 500 条），使用「◀ 上一页 / 下一页 ▶」翻页；「📤 导出 CSV」会把全部匹配结果（不分页）一次性导出。

**Q17: 素材标签怎么设置和使用？**
A: 在「素材信息」视图的「标签与备注」分组输入标签（多个用逗号分隔，如 `日戏,主镜头`），保存后立即生效；「素材检索」视图可按标签关键字筛选（带自动补全）。标签与备注会随 CSV 导出与项目归档一起保存。

**Q18: 归档 / 恢复会损坏我的素材吗？**
A: 不会。恢复采用「临时目录写入 → 校验全部通过后再移入目标」策略，校验失败的归档不会留下半成品；同时内置成员路径、解压大小与符号链接安全检查，拒绝恶意归档。归档包可先在任何 zip 工具中打开检查。

**Q19: 相机卡自动化怎么配置？**
A: 在「设置 → 存储卡」勾选「检测到相机卡后自动执行配置」，再选择「自动关联项目」与「自动备份方案」（备份方案需先在「数据备份」视图保存），并按需勾选「自动导入素材」和/或「自动执行备份方案」。

**Q20: 备份中断了怎么办？**
A: 不需要重新备份。在「数据备份」视图下方的「备份历史」选中该作业，点击「↻ 重试失败文件」，系统只补拷缺失/失败文件，目标中已存在且校验一致的文件自动跳过（断点续传）。

**Q21: 备份方案有什么作用？**
A: 备份方案保存一组备份目标、校验算法与验证选项，可下拉复用，避免每次手工重复配置；同时作为「相机卡自动化」自动备份的依据。
