# DIT 工作站 - 专业摄影数据管理 用户手册

## 应用总览

**应用名称**：DIT 工作站 - 专业摄影数据管理

DIT 工作站是一款面向专业摄影工作流的桌面应用，覆盖从媒体导入、数据备份、RAW 提取、文件重命名、拍摄日志、素材检索到报告生成的完整数据管理链路，帮助 DIT（数字影像工程师）在片场高效、安全地管理海量摄影素材。

### 主窗口布局

- **左侧导航栏**：宽度 200px，深色主题，列示 7 个功能模块入口。
- **右侧内容区**：展示当前选中模块的操作界面。
- **窗口尺寸**：最小 1200×800，默认 1400×900。

### 导航栏功能模块

| 图标 | 模块名称 | 说明 |
| --- | --- | --- |
| 📁 | 媒体导入 | 扫描并导入源文件夹中的图片/视频/RAW 文件 |
| 📦 | 数据备份 | 多目标并行备份源数据，支持校验与 MHL 清单 |
| 🎞 | RAW 提取 | 依据筛选后 JPG 反查并提取对应 RAW 文件 |
| ✏️ | 文件重命名 | 按命名规则模板批量重命名文件 |
| 📋 | 拍摄日志 | 记录场景/镜头/镜次信息并关联素材 |
| 🔍 | 素材检索 | 按项目/关键词/场景/镜头/日志等多条件检索素材 |
| 📊 | 报告生成 | 生成数据备份报告或素材统计报告（PDF） |

### 数据与文件位置

| 项目 | 路径 |
| --- | --- |
| 数据库文件 | `~/.dit_workstation/dit_workstation.db`（SQLite 格式） |
| 报告输出目录 | `~/Documents/DIT_Reports/` |
| 日志文件目录 | `~/.dit_workstation/logs/` |

## 模块 1: 媒体导入

### 界面布局

界面采用左右分栏结构：

- **左侧**：项目列表 + 「+ 新建」按钮。
- **右侧**：
  - **导入源**：文件夹选择输入框 + 「浏览...」按钮。
  - **扫描选项**：复选框组（递归扫描 / 包含图片 / 包含视频 / 包含 RAW）+ 「扫描」按钮。
  - **待导入文件表格**：4 列（文件名 / 类型 / 大小 / 路径）。
  - **导入选项**：计算校验和复选框、复制到工作区复选框 + 工作区目录选择、关联拍摄日志下拉框。
  - **操作按钮**：导入按钮 + 取消按钮。
  - **进度与状态**：进度条、状态标签、导入日志。

### 操作流程

1. 在左侧项目列表选择一个项目（或点「+ 新建」创建新项目）。
2. 点击「浏览...」选择包含媒体文件的文件夹。
3. 勾选要扫描的文件类型（图片 / 视频 / RAW），可勾选「递归扫描」包含子文件夹。
4. 点击「扫描」按钮，待导入文件表格显示扫描结果。
5. 在导入选项中：
   - 勾选「计算校验和」为每个文件生成唯一哈希值用于查重；
   - 如需将文件复制到工作区，勾选「复制到工作区」并选择目录；
   - 如需关联拍摄日志，从下拉框选择已创建的日志（会自动带出 scene / shot 信息）。
6. 点击「导入」按钮开始导入，进度条显示进度，可随时点「取消」中断。
7. 导入完成弹出结果：成功 N 个、跳过 N 个（重复）、失败 N 个。

### 两种导入模式

- **引用模式（默认）**：原文件位置保持不动，仅记录路径到数据库。
- **复制模式（勾选「复制到工作区」）**：将文件复制到指定工作区目录，重名文件自动加 `_N` 后缀。

### 查重逻辑

按项目内文件路径查重，已导入的文件会被跳过。

### 注意事项

- 导入前请确保存储卡 / 源文件夹可正常读取。
- 校验和计算会增加导入时间，但便于后续完整性验证。
- 关联拍摄日志后，素材的 scene / shot 字段会自动填充日志对应值。
- 切换到其他界面再回来时，项目列表会自动刷新。

## 模块 2: 数据备份

### 界面布局

- **源路径选择**：输入框 + 「浏览...」按钮。
- **备份目标列表**：目标路径列表 + 「+ 添加目标」/「移除」按钮。
- **配置区**：校验算法下拉框（XXHash64 / MD5）+ 「拷贝后验证」复选框。
- **操作按钮**：开始备份 / 取消按钮。
- **进度与状态**：进度条（0-1000 精度）、状态标签、操作日志。

### 操作流程

1. 点击源路径旁的「浏览...」选择存储卡或源文件夹，系统自动扫描显示文件数和总大小。
2. 点击「+ 添加目标」逐个添加备份目标路径（支持多目标并行备份）。
3. 选择校验算法（推荐 XXHash64，速度更快）和是否「拷贝后验证」。
4. 点击「开始备份」，系统并行拷贝到所有目标。
5. 每个文件拷贝完成后自动验证（如开启），进度条实时更新。
6. 完成后弹出窗口显示每个目标的成功 / 失败状态。

### 技术细节

- 多目标使用线程池并行拷贝（最多 4 个并行）。
- 拷贝缓冲区 8MB，校验和缓冲区 4MB。
- 拷贝后验证：对目标文件重新计算校验和并与源文件比对，不一致则报错。
- 支持 MHL（Media Hash List）2.0 格式哈希清单生成。

### 注意事项

- 备份过程中不要拔出存储卡。
- 建议始终开启「拷贝后验证」确保数据完整性。
- 多目标备份时，某个目标失败不影响其他目标。

## 模块 3: RAW 提取

### 界面布局

- **路径配置组**：JPG 文件夹、RAW 源文件夹、输出文件夹，各带「浏览...」按钮。
- **选项**：「提取后验证」复选框。
- **操作按钮**：扫描匹配 / 开始提取 / 取消按钮。
- **匹配结果表格**：3 列（JPG 文件 / 匹配 RAW / 状态）。
- **进度与状态**：进度条、状态标签。

### 操作流程

1. 设置「JPG 文件夹」（筛选后的 JPG 所在目录）。
2. 设置「RAW 源文件夹」（原始 RAW 文件所在目录）。
3. 设置「输出文件夹」（提取后的 RAW 存放目录）。
4. 可勾选「提取后验证」。
5. 点击「扫描匹配」查看 JPG 与 RAW 的匹配结果（状态显示「已匹配」或「未找到」）。
6. 确认匹配结果后点击「开始提取」，系统将匹配的 RAW 文件复制到输出目录。
7. 完成后显示提取数量、未找到数量、失败数量。

### 匹配逻辑

按文件名 stem（不含扩展名）小写比对，例如 `IMG_001.jpg` 匹配 `IMG_001.cr2`。

### 注意事项

- 确保 JPG 和 RAW 文件名前缀一致。
- 重名文件自动加 `_N` 后缀。

## 模块 4: 文件重命名

### 界面布局

- **文件夹选择**：输入框 + 「浏览...」按钮。
- **命名规则组**：可编辑下拉模板（4 种预设 + 自定义）。
- **参数输入框**：场景号 / 镜头号 / 镜次号、前缀 / 起始序号 / 序号位数。
- **操作按钮**：预览 / 执行重命名按钮。
- **预览结果表格**：2 列（原文件名 / 新文件名）。

### 操作流程

1. 点击「浏览...」选择要重命名的文件夹，系统自动扫描文件。
2. 在命名规则下拉框选择或自定义模板。
3. 填写场景号、镜头号、镜次（如 `S001` / `001A` / `T01`）。
4. 设置前缀、起始序号、序号位数（如 `001`）。
5. 点击「预览」查看重命名结果。
6. 确认无误后点击「执行重命名」（不可撤销）。

### 模板变量

| 变量 | 含义 |
| --- | --- |
| `{scene}` | 场景号 |
| `{shot}` | 镜头号 |
| `{take}` | 镜次号 |
| `{original}` | 原文件名（不含扩展名） |
| `{number}` | 序号（从起始序号开始，按序号位数补零） |
| `{prefix}` | 自定义前缀 |
| `{suffix}` | 自定义后缀 |
| `{date}` | 当前日期（YYYYMMDD） |

### 预设模板

1. `{scene}_{shot}_{take}_{original}`
2. `{prefix}_{number}_{original}`
3. `{date}_{scene}_{shot}_{original}`
4. `{scene}_{shot}_{take}_{number}`

### 注意事项

- 执行重命名不可撤销，请先预览确认。
- 重名文件自动加 `_N` 后缀防止覆盖。
- 文件扩展名保持不变。

## 模块 5: 拍摄日志

### 界面布局

左侧为项目列表 + 「新建项目」/「删除」按钮。右侧上下分栏：

- **上部**：
  - 拍摄日志表单（场景 / 镜头 / 镜次、摄影机 / 镜头、ISO / 光圈 / 快门、描述、备注、「选择关联素材」按钮 + 已选数量标签、「添加日志」按钮）。
  - 日志列表表格（场景 / 镜头 / 镜次 / 描述 / 摄影机 / 时间 6 列）。
  - 「删除日志」按钮。
- **下部**：双标签页
  - **标签页「关联素材」**：关联素材 / 解除关联按钮 + 素材表格（文件名 / 类型 / 大小 / 场景 / 镜头 5 列）。
  - **标签页「项目素材」**：为选中素材创建日志按钮 + 素材表格（文件名 / 类型 / 大小 / 场景 / 镜头 / 关联状态 6 列，支持多选）。

### 操作流程 — 方式一（先填表单再选素材）

1. 在左侧选择项目。
2. 在表单填写场景 / 镜头 / 镜次等信息。
3. 点击「选择关联素材」弹出对话框，可搜索过滤，勾选要关联的素材，确认。
4. 标签显示「已选 N 个素材」。
5. 点击「添加日志」，系统创建日志并关联选中素材，同时把 scene / shot 同步写入素材。
6. 自动选中新日志，底部「关联素材」标签页显示刚关联的素材。
7. 弹出成功提示。

### 操作流程 — 方式二（先选素材再填表单）

1. 在左侧选择项目。
2. 切换到底部「项目素材」标签页，显示项目所有已导入素材及关联状态。
3. 多选要记录日志的素材（Ctrl / Cmd + 点击多选）。
4. 点击「为选中素材创建日志」，系统将选中素材加入待关联列表。
5. 在上方表单填写场景 / 镜头 / 镜次等信息。
6. 点击「添加日志」，系统创建日志并关联素材。

### 关联素材管理

- 选中某条日志后，底部「关联素材」标签页显示该日志关联的所有素材。
- 点「+ 关联素材」可为当前日志追加关联更多素材（弹出选择对话框）。
- 选中素材后点「解除关联」可取消关联（素材不被删除，仅清除 `log_id`）。
- 删除日志时，关联素材的 `log_id` 会被级联清除（素材不被删除）。

### 注意事项

- 创建日志时同步 scene / shot 到素材，解除关联时不会恢复素材的 scene / shot。
- 项目素材标签页的「关联状态」列显示每个素材是否已关联日志。
- 切换到拍摄日志界面时会自动刷新项目列表。

## 模块 6: 素材检索

### 界面布局

- **搜索条件组**：项目下拉框 + 关键词输入框、场景 / 镜头 / 类型下拉框、拍摄日志下拉框、日期范围 + 限定复选框。
- **操作按钮**：搜索 / 重置按钮。
- **结果计数标签**：显示匹配数量。
- **结果表格**：8 列（文件名 / 类型 / 大小 / 场景 / 镜头 / 关联日志 / 校验和 / 导入时间）。

### 操作流程

1. 选择项目（可选「全部项目」）。
2. 输入关键词（按文件名模糊匹配）。
3. 可选填写场景号、镜头号、选择文件类型。
4. 可选选择拍摄日志（筛选关联了某条日志的素材）。
5. 可选勾选「限定日期范围」并设置起止日期。
6. 点击「搜索」按钮，结果表格显示匹配的素材。
7. 「关联日志」列显示素材关联的日志信息（场景 / 镜头 / 镜次）。
8. 点击「重置」清空所有条件。

### 注意事项

- 关键词按文件名模糊匹配（LIKE 查询）。
- 切换项目时拍摄日志下拉框会自动刷新。
- 切换到素材检索界面时会自动刷新项目列表。

## 模块 7: 报告生成

### 界面布局

- **报告配置组**：项目下拉框、报告类型下拉框（数据备份报告 / 素材统计报告）、输出路径选择。
- **操作按钮**：生成报告按钮。
- **状态标签** 与 **生成日志**。

### 操作流程

1. 从下拉框选择项目。
2. 选择报告类型：
   - **数据备份报告**：包含项目信息、备份任务详情、目标状态。
   - **素材统计报告**：包含项目信息、素材按场景统计。
3. 选择输出路径（默认 `~/Documents/DIT_Reports/`，文件名带时间戳）。
4. 点击「生成报告」，后台生成 PDF。
5. 完成后弹窗显示报告路径。

### 注意事项

- PDF 报告支持中文显示（跨平台自动查找中文字体）。
- 报告文件名格式包含时间戳，不会覆盖已有报告。

## FAQ 常见问题

**Q1: 数据库文件存在哪里？**
A: `~/.dit_workstation/dit_workstation.db`（SQLite 格式，可用任何 SQLite 工具查看）。

**Q2: 导入时重复文件会怎样？**
A: 系统按项目内文件路径查重，已导入的文件会被自动跳过并计入「跳过」数量。

**Q3: 导入 / 备份过程中可以取消吗？**
A: 可以，点击「取消」按钮即可中断，已处理的部分不受影响。

**Q4: 复制模式下重名文件怎么处理？**
A: 自动在文件名后加 `_N` 后缀（如 `file_1.cr2`、`file_2.cr2`）。

**Q5: 报告中中文显示乱码怎么办？**
A: 系统会自动查找系统中文字体（macOS: PingFang，Windows: 微软雅黑，Linux: 文泉驿 / Noto），请确保系统已安装中文字体。

**Q6: 删除项目会删除实际文件吗？**
A: 不会。删除项目仅删除数据库记录（项目、日志、素材记录），不会删除磁盘上的实际文件。

**Q7: 校验和有什么用？**
A: 校验和是文件的唯一指纹，用于查重和完整性验证。备份后验证可确保拷贝无误。

**Q8: 拍摄日志和素材如何关联？**
A: 有两种方式：1) 创建日志时选择关联素材；2) 在「项目素材」标签页多选素材后创建日志。关联后素材的 scene / shot 会同步日志信息。
